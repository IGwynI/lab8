# Ложкин Андрей КМБ2 Лабораторная №8

# Задание 1

## Задача 1

### Текст задачи

Разработать консольное приложение с дружественным интерфейсом с возможностью выбора
заданий для работы с «базой данных (БД)», хранящейся в бинарном файле. Перечень полей
(минимум 5), достаточно полно характеризующих заданную в варианте предметную область,
предложить самостоятельно (постараться отразить в перечне полей такие, которые требуют разных
типов данных). Приложение должно выполнять следующие функции:
1. Чтение базы данных из бинарного файла.
2. Просмотр базы данных.
3. Удаление элементов (по ключу).
4. Добавление элементов.
5. Реализация 4 запросов (формулировки запросов придумать самостоятельно). 2 запроса
должны возвращать перечень, 2 запроса одно значение.
В классе должны присутствовать свойства, конструкторы, перегруженный метод ToString(). Весь
функционал приложения реализовать в виде методов вспомогательного класса с помощью LINQзапросов.
Предусмотреть обработку возможных ошибок при работе программы

Каталог книг

### Алгоритм решения

Запросить у пользователя путь к файлу каталога (бинарный файл). 
Создать объект BookCatalog, передав путь. 
Вызвать метод LoadFromFile() для загрузки существующих данных из файла. 
Пока пользователь не выберет выход, отображать меню: 
Показать все книги; 
Добавить книгу; 
Удалить книгу по ISBN(International Standard Book Number); 
LINQ-запросы; 
Выход; 
Показать все книги -> вызвать PrintAll() (вывод таблицы или сообщения о пустом каталоге). 
Добавить книгу -> запросить все поля (название, автор, год, жанр, ISBN, страницы, цена, наличие), создать объект Book, вызвать AddBook(). 
Удалить книгу -> запросить ISBN, вызвать RemoveByISBN(). 
LINQ-запросы -> перейти в подменю запросов. 
Выход -> завершить программу. 
Добавление книги (AddBook): 
Проверить уникальность ISBN: если в списке уже есть книга с таким ISBN, выбросить исключение. 
Добавить книгу в список _books. 
Автоматически сохранить каталог в файл (SaveToFile()). 
Удаление книги (RemoveByISBN): 
Найти первую книгу с указанным ISBN (без учёта регистра). 
Если книга не найдена – вывести сообщение. 
Если найдена – удалить из списка и сохранить файл. 
Подменю LINQ-запросов: 
Пользователю предлагается выбрать один из запросов: 
Книги по автору; 
Доступные книги дешевле N; 
Общая стоимость всех книг; 
Среднее число страниц по жанру; 
Запрос 1 – Книги по автору: 
Ввести имя автора (или часть). 
Вызвать GetBooksByAuthor(author). 
Метод фильтрует список _books, оставляя книги, у которых поле Author содержит заданную подстроку. 
Вернуть результат; если список пуст, вывести сообщение. 
Запрос 2 – Доступные книги дешевле N: 
Ввести максимальную цену. 
Вызвать GetAvailableCheaperThan(maxPrice). 
Метод выбирает книги, удовлетворяющие двум условиям: IsAvailable == true и Price < maxPrice. 
Результат сортируется по возрастанию цены. 
Вывести список или сообщение об отсутствии. 
Запрос 3 – Общая стоимость всех книг: 
Вызвать GetTotalPrice(). 
Метод суммирует поле Price всех книг в списке с помощью LINQ-метода Sum. 
Вывести полученную сумму. 
Запрос 4 – Среднее число страниц по жанру: 
Ввести жанр. 
Вызвать GetAveragePagesByGenre(genre). 
Метод фильтрует книги по совпадению жанра, затем вычисляет среднее арифметическое PageCount. 
Вывести среднее или сообщение об отсутствии книг.
